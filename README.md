# 🏀 Bounceball Popup Game

Welcome to **Bounceball Popup Game** – a simple and fun desktop game where you control a bouncing ball and try to achieve the highest score possible. This project is open-source and welcomes contributions! 🎮✨

## 🚀 Features

- 🕹️ Intuitive controls for bouncing the ball
- 🏆 Score tracking
- 🎨 Simple UI
- 💻 Desktop application (see Releases for download)

## 📦 Getting Started

You can download the latest release from the [Releases page](https://github.com/kanishkagayanath/Bounceball_popup-game/releases).

### 🎲 How to Play

1. Download the application from [Releases](https://github.com/kanishkagayanath/Bounceball_popup-game/releases).
2. Run the game executable.
3. Use your keyboard or mouse to control the ball (see in-game instructions).
4. Try to keep the ball bouncing and beat your high score!
